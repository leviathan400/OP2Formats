# Working notes

State and plan for OP2Formats. Newest first; keep it short and current.

## Where it stands (2026-11-06)

- `op2-formats/` is an unmodified copy of op2-rs's `tools/crates/op2-formats` at commit
  `9798188` (commit `1705db3` here). It stays byte-identical to upstream; anything this repo
  needs lives outside that folder (root `Cargo.toml` workspace, `rust-toolchain.toml`,
  README, CI).
- Builds and tests on Windows (MSVC, Rust 1.99). With an OPU 1.4.1 install as `OP2_DIR` and
  `OP2_REQUIRE_DATA=1`, 68 of 69 tests pass with `--all-features`; the failure is
  `rules_and_tech_trees_parse`'s cross-check against op2-rs's recorded oracle runs, which
  only exist in op2-rs.
- CI (GitHub Actions, the repo is public since 2026-11-06) builds and tests the Rust crates on
  Ubuntu, Windows and macOS, with default and all features, without game data. Runs #6-#9
  failed only because a test expected no OPU downloader in an `--all-features` build (where
  it downloaded OPU's installer instead); fixed 2026-11-06.

- `op2formats-c/` (2026-10-23): the C interface, covering all of op2-formats (274 functions,
  one source file per area; see its README). Header generated by cbindgen 0.29.4 and
  committed. Checked on Windows with MSVC from C++ (DLL and static) and C, all 25 structs
  the same size and alignment in C and Rust; `tests/c_api.rs` and `tests/all_areas.rs`
  (14 tests) pass with real data. The OPU installer functions pass against OPU 1.4.1's
  official installer (`OP2_OPU_INSTALLER`: verify, NSIS files, an install of 665 files into a
  temporary folder); GOG's installer functions are untested against a real installer.
- CMake (2026-10-23): top-level `CMakeLists.txt` runs Cargo and defines
  `OP2Formats::OP2Formats` / `::shared` / `::static` and `op2formats_copy_runtime`; installs a
  `find_package` config (`cmake/`). Checked with MSVC 2022 and CMake 3.31 (Ninja and the
  Visual Studio generator, Debug and Release, shared and static, installed and found).
- `op2-opm/` (2026-11-04): reads and writes `.opm` missions (see its README); in the C
  interface as `op2f_opm_*` (299 functions in all now, 32 structs checked the same size in
  C, C++ and Rust). Fixtures: two editor-saved missions from the user's own projects.
  Next for it: effective mission (variant + difficulty merged), coordinates, unit art names,
  validation; setters in the C interface (C code edits through the canonical JSON for now).

## Next steps

1. **C interface**: test the GOG installer functions with GOG's offline installer. Try MinGW
   (`x86_64-pc-windows-gnu`, what op2remake's Qt build uses; the CMake branch for it is
   written but untried) and the C/CMake side on Linux and macOS.
2. **CI**: add the C side (cbindgen's output matches the committed header, the CMake example
   builds) and a MinGW job.
3. **Upstream**: tell bufke about this repo; send reader fixes to op2-rs as merge requests;
   to take in upstream changes, copy the folder again from a newer op2-rs commit and update
   the commit named in the README.
4. **Name**: the crate is still `op2-formats`. Decide before publishing anywhere (crates.io
   needs a unique name; `outpost2-formats` was one idea).
